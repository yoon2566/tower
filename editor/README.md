# 타워디펜스 AI 편집기

기존 UI에 AI 수정 / HTML 다운로드 버튼을 추가합니다.

- 모델: anthropic/claude-haiku-5.5. Messages API output_config.effort=high, thinking.type=disabled.
- 서버 secret: OPENROUTER_API_KEY. 키는 클라이언트나 다운로드 파일에 포함하지 않습니다.
- 접속/새로고침 시 항상 최신 원본 게임과 새 대화로 시작합니다. 저장된 수정본과 지난 대화는 자동 적용하지 않습니다.
- 개인 코드와 대화는 현재 페이지의 메모리에서만 유지합니다. 지난 수정 불러오기 및 브라우저 자동 저장은 사용하지 않습니다. 보관/이동은 HTML 다운로드·불러오기를 사용합니다. 과거 localStorage 데이터는 읽거나 삭제하지 않습니다.
- 이전 버전: 현재 세션 최근 10개. 새로고침하면 원본으로 시작합니다.
- 다운로드: React, 아이콘, CSS, 원본 소스와 변환 완료 코드를 포함하는 오프라인 단일 HTML (원본 약 416KB). Babel은 포함하지 않습니다.
- 첫 실행은 빌드 때 변환된 코드를 사용합니다. 수정/기존 HTML 불러오기 때만 compiler.js를 지연 로드합니다. 변환 결과는 현재 페이지 메모리에만 캐시합니다. 검증이 끝난 iframe을 그대로 표시해 중복 실행하지 않습니다.
- 대화: 최근 24개 메시지(각 최대 10,000자)를 현재 전체 코드와 함께 전송하고 현재 페이지 메모리에서만 유지합니다. 모델의 1M 컨텍스트를 별도로 늘리는 옵션은 없습니다. 앱은 코드 최대 2,000,000자, 입력 10,000자, 출력 128,000토큰을 허용합니다.
- JSON/수정 위치 오류는 서버에서 1회 재시도합니다. 문법/초기 실행 오류는 브라우저에서 실패 코드와 오류를 보내 1회 복구합니다. 따라서 최악의 경우 한 요청이 모델을 최대 4회 호출할 수 있습니다. 실패 시 마지막 정상 게임을 유지합니다.
- AI 코드는 allow-scripts iframe에서 실행하고 CSP로 외부 네트워크를 차단합니다. 적용 전 문법/초기 렌더링 검사. 모든 게임 동작을 자동 보장하지는 않습니다.
- 기본 Tailwind CSS는 빌드 시 생성합니다. 새 스타일은 인라인 또는 styles.css를 사용합니다.
- D1/R2는 사용하지 않습니다.

빌드: npm ci 후 npm run build. 배포: npx wrangler pages deploy dist --project-name tower --branch main. GitHub main 자동 배포도 같은 빌드 명령과 dist를 사용합니다.

검증 서버: OPENROUTER_API_KEY를 프로세스 환경변수로 전달하고 node editor/local-server.mjs 실행 (127.0.0.1:8801). 키 파일은 만들지 않습니다.
TEST_URL 환경변수를 해당 주소로 지정하고 node editor/verify.mjs 실행. 실제 유료 AI 요청, 저장/재접속, 다운로드/오프라인 실행, 불러오기/되돌리기 검사. Chrome 필요.
node editor/verify-upgrade.mjs는 초기 변환기 미요청, 모델 설정/대화 전달, 수정 위치 오류 재시도, 실행 오류 복구, 캐시 재접속을 검사합니다 (모델 응답은 모의 처리).
